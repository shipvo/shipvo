# How many simulators run at once

Measured on 2026-11-07 with `scripts/sim-bench/scale.mjs` on a 2-CPU, 7.8 GB Linux machine (Node v22.23.4), app `apps/chess`. Sessions open in batches of 10. After each batch the script reads a screen from the first, middle and last session.

**Result: 110 simulators open at once, every sampled one answering. Each took 57.1 MB of memory, measured at 100 open.** Up to 100 open, each batch of 10 started in 5.1 seconds or less. At 110 a batch took 27.6 seconds, and the next 10 did not start.

Idle, before any session: 7234 MB available. Per-simulator memory is the fall in available memory divided by the open sessions, taken at 100 open, the last step before memory ran short. Raw numbers: [scale-2026-11-07.json](scale-2026-11-07.json). Run it yourself: `node scripts/sim-bench/scale.mjs --max 120 --step 10`.
