# How many simulators run at once: 4 CPUs, 15.6 GB

Measured on 2026-11-07 with `scripts/sim-bench/scale.mjs` on a 4-CPU, 15.6 GB Linux machine (a GitHub Actions runner, Node v22.23.4), app `apps/chess`. Sessions open in batches of 10. After each batch the script reads a screen from the first, middle and last session. The 2-CPU, 7.8 GB result is in [scale-2026-11-07.md](scale-2026-11-07.md).

**Result: 260 simulators open at once, every sampled one answering. Each took 53.9 MB of memory, measured at 260 open.** Every batch of 10 started in 5.6 seconds or less after the first. The script stopped at 260 with 578 MB of memory still available, by its own rule to keep the machine responsive.
