# capacitor-sample

A minimal Capacitor 8 app. Later Capacitor adapter work (Device Lab, simulator, EAS setup, build template) tests against it. It is private and is not published. Epic: #297.

The app has a list screen, a detail screen, and a button that shows the current release number. Until an adapter sets `window.__SHIPVO_RELEASE__`, the button shows `Release: embedded build`.

## Layout

- `src/`: TypeScript web app. `pnpm build` compiles it with `tsc` and copies `index.html` to `www/`.
- `capacitor.config.ts`: app id `dev.shipvo.capacitorsample`, `webDir: www`.
- `android/`, `ios/`: generated by `npx cap add`, committed. The shared Xcode scheme is `ios/App/App.xcodeproj/xcshareddata/xcschemes/App.xcscheme`.

## Updates

`pnpm build` bundles the app with `@shipvo/capacitor`. Set `SHIPVO_PUBLIC_KEY` and `SHIPVO_BASE_URL` before building to turn on updates. The Android project includes the plugin from `packages/capacitor/android`. The **Check for update** button runs `checkForUpdate({ apply: true })`.

## Test

```bash
pnpm install --frozen-lockfile
pnpm --filter capacitor-sample test
```

This builds the web app and runs the unit tests.

## Run in a browser

```bash
pnpm --filter capacitor-sample serve
```

Open http://localhost:5173 (set `PORT` to change it).

## Run on an Android emulator

Needs the Android SDK, JDK 21 and an emulator.

```bash
cd apps/capacitor-sample
pnpm sync
npx cap run android      # pick a running emulator or AVD
# or: cd android && ./gradlew assembleDebug
```

## Run on the iOS Simulator

Needs macOS and Xcode.

```bash
cd apps/capacitor-sample
pnpm sync
npx cap run ios          # pick a simulator
# or: xcodebuild -project ios/App/App.xcodeproj -scheme App -destination 'generic/platform=iOS Simulator' build
```

## Fresh clone

`www/` and the copied web assets inside `android/` and `ios/` are ignored. `pnpm sync` rebuilds them and runs `cap sync`.
