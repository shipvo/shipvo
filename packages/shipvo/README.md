# shipvo

The Shipvo CLI under its short name. It is the same as [`@shipvo/cli`](https://www.npmjs.com/package/@shipvo/cli).

```bash
npx shipvo init myshop      # or: npm create shipvo myshop
cd myshop && npm install
npx shipvo sim              # open the app on a simulated phone in your browser
npx shipvo publish          # send a signed over-the-air update
```

Install it globally to type `shipvo` anywhere: `npm i -g shipvo`.
