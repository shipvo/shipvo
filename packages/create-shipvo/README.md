# create-shipvo

Start a new [Shipvo](https://shipvo.dev) app:

```bash
npm create shipvo myshop
cd myshop && npm install
npx shipvo sim
```

It runs `shipvo init` from [`@shipvo/cli`](https://www.npmjs.com/package/@shipvo/cli); options after the folder name go to `shipvo init` (for example `npm create shipvo myshop -- --template shop`).
