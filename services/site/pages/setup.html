Set up

Set up with your agent.

Pick one line. Each one gets your coding agent (Claude Code, Cursor, Codex) ready to set up Shipvo in your project, run it on Shipvo Phone, test it, and publish.

1. With npm: install the skill

The skill teaches your agent the exact shipvo commands.

npx skills add shipvo/shipvo --skill shipvo -g

2. Without the skill tool: one line for your system

Run it in your project folder. It needs Node 22 or newer. It tells you what it will run, then runs npx -y @shipvo/cli agents setup in the current folder. It installs nothing outside the project and needs no admin rights. If Node is missing, it tells you how to install it. Read the script first: install.sh (macOS, Linux, WSL) or install.ps1 (Windows).

macOS and Linux

curl -fsSL https://shipvo.dev/install.sh | bash

Windows (PowerShell)

irm https://shipvo.dev/install.ps1 | iex

3. Paste this to your agent

Set up Shipvo in this project: run `npx -y @shipvo/cli agents setup`, then follow what it prints.
