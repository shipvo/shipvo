Set up

Set up with your agent.

Pick one line. Each one gets your coding agent (Claude Code, Cursor, Codex) ready to set up Shipvo in your project, run it on Shipvo Phone, test it, and publish.

1. With npm: install the skill

The skill teaches your agent the exact shipvo commands.

npx skills add shipvo/shipvo --skill shipvo -g

2. Without the skill tool: one curl line

Run it in your project folder. It needs Node 22 or newer and npm. It tells you what it will run, then runs npx -y @shipvo/cli agents setup in the current folder. It installs nothing outside the project and does not use sudo. If Node is missing, it says how to install it. You can read the script first.

curl -fsSL https://shipvo.dev/install.sh | bash

3. Paste this to your agent

Set up Shipvo in this project: run `npx -y @shipvo/cli agents setup`, then follow what it prints.

Windows: there is no PowerShell installer yet. Use the skills line (1) or the paste line (3), from a terminal where Node 22 is installed.
