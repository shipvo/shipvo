- `@shipvo/schema`, `@shipvo/cli`: two more `policy` rules in `shipvo.json`: `maxCohortForAgents` (a band name or a percent) and `requireStageBeforeFull` (`{ percent: 1 | 10, minHours }`). New `shipvo publish --dry-run-policy` checks the policy alone, builds nothing, and exits 1 naming the rule if refused. Only `publish --dry-run` and `--dry-run-policy` run the policy; a real publish and `promote` do not. Unknown keys are still an error.
- Migration: none; new optional fields and a new flag.
