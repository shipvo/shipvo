- `@shipvo/cli`: new `spawnBin` and `runBin` helpers start `npx`, `pnpm`, `npm`, `yarn` and `node_modules/.bin` programs through their `.cmd` shim with quoted args on Windows. `shipvo preview`, `shipvo run --native`, `shipvo sim`, `shipvo explore`, the web export in `shipvo publish`, `shipvo eas` and the installs in `shipvo init` (adopt mode) use them. The `PN_SIM=1 npx …` shell prefix is now an `env` option. Linux and macOS behaviour is unchanged.
- Migration: none.
