- `@shipvo/sim`: the phone frame has a Settings screen (home-screen icon and the shade gear, both skins) with dark mode, font size (small, default, large, extra-large), bold text, reduce motion, language (en, fr, ar) and right-to-left.
- `@shipvo/mcp`: new tools `get_settings` and `set_setting`. Unknown keys fail with `unknown_setting`, bad values with `bad_value`. Language `ar` turns RTL on. Each change is in `device_log` as `setting_changed`, simulated.
- `@shipvo/device`: the simulated device state gains `fontSize`, `boldText`, `reduceMotion`, `language` and `rtl`. In the web export the app sees them through `matchMedia` (colour scheme, reduced motion; this is what `Appearance` and `AccessibilityInfo.isReduceMotionEnabled` read), `devicePixelRatio` (what `PixelRatio.getFontScale()` reads on web), `<html dir lang>`, `navigator.language` and `Intl` default locale. Bold text is exposed as `data-pn-bold-text` on `<html>` and in `device.settings()`.
- Migration: none; new fields and tools, defaults match the old behaviour.
