- mcp: new tool `upload_build` (stdio only) builds the app with the simulated device through `shipvo sim --hosted`, uploads it to the hosted phone for your key and returns a build id that expires on its own. Builds are private to the key's account. `open_app("myapp@build:<id>")` checks the build and answers `build_not_served` until the hosted phone serves uploaded builds. New error codes: `build_not_found`, `build_expired`, `build_not_served`, `build_too_large`, `no_api_key`, `upload_failed`. No migration needed: this adds a tool and does not change existing ones.
- cli: `shipvo sim --hosted` builds, packs and uploads the app to the hosted phone and prints the build id and expiry (`--json` supported).
