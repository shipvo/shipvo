- `@shipvo/schema`: `Telemetry` gains optional `install_id`, `install_token` and `sig`; new `TelemetryRegister`.
- `@shipvo/runtime`: new `ensureInstallIdentity` and `signReport` register an install once and sign each report.
- Control plane: auto-halt counts only verified reports, one vote per install, from at least 20 installs on 3 networks. The default `min_reports` is now 50 (was 20). Suspicious bursts are held for the owner (`approvals_list`, kind `halt`). `POST /t` and the new `POST /t/register` are rate limited. Revert alerts need 3 verified installs.
- Migration: run migration `0019_telemetry_trust.sql` (additive). Set `TELEMETRY_SECRET` (or keep `OWNER_TOKEN`) so install tokens can be signed. Old runtimes keep working but their reports are unverified: **auto-halt will not fire for an app until it ships a runtime that signs reports** (call `ensureInstallIdentity` and `signReport` where you send telemetry). Pass `min_installs` / `min_networks` in the halt-config body to tune.
