- phone: `open_url` now resolves the URL first. Apps declare `schemes` in `phone.json` (and `shipvo.json`); a match returns the owning app id (`app`), text without a scheme fails with `invalid_url`, and a scheme no app declares fails with `no_handler`. With no declared schemes the URL goes to the app's URL listener as before. Delivering the URL to the matched app comes in the next slice.
