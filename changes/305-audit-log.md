- Control plane: append-only audit log. New table `audit_log` and `GET /audit/:app` (newest first, `?limit=` up to 200, `?before=<id>` for paging). It needs the app's publish token, the owner token or an admin session; without one it returns 401. Each publish (pointer upload or owner `publish`), rollback (a pointer upload with a lower release than the one it replaces) and automatic halt writes one row with actor, actor kind, before and after. One release uploaded to several band keys writes one row, not one per band. `release` is the OTA release number; for owner `publish` it is null and the content version is in `before` and `after` as `content_version`. A halt row's `before` is the release that was halted earlier, if any. `next_before` is set only when another page exists. Tokens and keys are never stored. A failed audit write logs a warning and does not block the action.
- Migration: run `0015_audit_log.sql` (one new table, additive). Until it runs, actions still succeed and a warning is logged.
