- `@shipvo/device` (web): `net.online()` and the new optional `net.connection()` follow the active network profile. `offline` is not connected; `2g`, `3g`, `slow-4g`, `low-end-4g` and `spotty` report a cellular type with the matching generation (`spotty` reports `3g`). `net.onChange` subscribers are notified when the connection changes, including a move between cellular profiles such as `3g` to `2g` and `reset()` (the callback still receives the `online` boolean). Set it with `__pnDevice.set({ networkProfile })`.
- Migration: none; `online` keeps today's values.
- `@shipvo/sim`: `set_network_profile` also tells the page, so the app's connectivity follows it.
