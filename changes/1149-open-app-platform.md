- mcp-tools: `open_app` takes an optional `platform` (`android` or `ios`). Existing calls keep working. The local and hosted servers share this one schema. The result names the platform of the phone that opened. If it differs from the one asked for, or `attach: "always"` meets a live run of the other platform, the call returns `platform_mismatch`. With `attach: "auto"`, a live run of the other platform is skipped and a headless session opens.
