- mcp-tools: `open_app` takes an optional `platform` (`android` or `ios`). Existing calls keep working. The local and hosted servers share this one schema. The request sends it as `device.platform`. When the simulator reports the platform of the phone it opened, the result names it, and a different platform returns `platform_mismatch`. A simulator that reports none is not an error. Also, if `attach: "always"` meets a live run of the other platform, the call returns `platform_mismatch`. With `attach: "auto"`, a live run of the other platform is skipped and a headless session opens.
