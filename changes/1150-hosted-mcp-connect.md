- `@shipvo/cli`: `shipvo agents setup --hosted` writes the remote MCP config (URL plus Authorization header) for Claude Code, Cursor, VS Code and Windsurf, and prints the key-in-URL form for ChatGPT. It signs you in first if there is no key. Keys go only into user-level files or git-ignored project files; otherwise the block is printed with the reason.
- `sim.shipvo.dev` and the control plane: OAuth sign-in for the hosted MCP server (protected resource metadata, authorization server metadata, dynamic client registration, PKCE) backed by GitHub sign-in. `claude mcp add --transport http shipvo https://sim.shipvo.dev/mcp` connects by signing in. The token is the same per-account key as `shipvo login`; hashing, 30-day expiry and revocation are unchanged. Discovery without a key works as before.
- Migration: none. The control plane needs `GITHUB_CLIENT_SECRET` set for OAuth sign-in (the GitHub OAuth app's callback URL is `<control plane>/oauth/callback`).
