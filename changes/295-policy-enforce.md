- `control-plane`: publishing a release pointer (including `shipvo promote`) now also enforces `blockedWeekdays`/`blockedAfterHour` and `requireStageBeforeFull`, not only `maxBand` and `agentMaxBand`. A refusal is 403 `{ code: "policy_refused", rule, reason }` with one audit row. Weekday rules use the policy's `timeZone`, or UTC if it has none. `requireStageBeforeFull` refuses a `b2` pointer unless the same release has a signed pointer on `b0`/`b1` (reaching at least `percent`; `b0` is 1%, `b1` is 10%) issued at least `minHours` ago.
- `control-plane`: `set_release_policy` takes `blockedWeekdays`, `blockedAfterHour`, `timeZone`, `stagePercent` and `stageMinHours`. Policies stored before keep working.
- `schema`: new optional `policy.timeZone` (IANA name) and exported `checkPolicy`, `BAND_PERCENT`, `PolicyResult`. The CLI now uses the shared `checkPolicy`; `shipvo.json` files without `timeZone` behave as before (machine local time). Migration: none.
- Migration: no database change.
