- Control plane: a person can set a monthly spend limit per installed app (`PUT` and `GET /phone/apps/<app>/spend-limit`). The default is 0, so no money moves. An assistant token gets 403. A money action over the limit is refused with `spend_limit`, `limit` and `spent` before any call is made, and each change and refusal is audited. New migration `0025_spend_limit.sql` (additive). No migration steps needed for existing apps.
