- `@shipvo/sim`: `POST /session` reads `build_url`, loads the uploaded build from an allow-listed host (size cap and timeout) and serves it as the app. The reply carries `build: <id>`, so `open_app("<app>@build:<id>")` opens the build on Android and iOS sessions. A bad or unreachable URL returns `bad_build_url`, `build_url_not_allowed`, `build_unreachable` or `build_too_large`, and no session is left behind.
- Migration: none. Extra build hosts can be added with `--build-hosts` or `PN_BUILD_HOSTS`.
- `@shipvo/sim`: uploaded builds are cached within a memory budget (least recently used files and builds are dropped, builds a live session runs are kept). A build's `index.html` is fetched again at each session start. Malformed or out-of-build paths on `/b/<id>/` return `400 bad_path`. Allowed hosts are the control-plane host and `sim.shipvo.dev`; a self-hosted upload host needs `--build-hosts` / `PN_BUILD_HOSTS` (the upload path in `@shipvo/mcp` uses `SHIPVO_HOSTED_URL`). Limits can be set with `PN_BUILD_CACHE_BYTES` and `PN_BUILD_CACHE_BUILDS`.
