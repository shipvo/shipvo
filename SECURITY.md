# Security policy

Liveo delivers code to devices, so signing and verification bugs are treated as critical.

**Report a vulnerability** privately through GitHub's [private vulnerability reporting](https://github.com/purenativedev/purenative/security/advisories/new). Don't open a public issue. We aim to acknowledge reports within 72 hours.

In scope: signature or hash verification bypass, pointer or bundle substitution, rollback or crash-loop guard bypass, control-plane authentication, and secrets exposure in workflows.
